# 写真と季節情報

公開用写真は `scripts/optimize-photos.py` で WebP を生成する。一覧は最大640px・品質78、詳細は最大1440px・品質83。縦横比を維持し、EXIFの向きを反映、位置情報などのEXIFは出力しない。写真の撮影者・ライセンス・出典は維持する。ブラウザはsrcsetで適切な解像度を選ぶ。

2026-09-27時点で許諾付きURL205件のうち86地点を変換・ローカルR2に配置。119件は403(103)、404(14)、画像として解釈できない応答(2)。取得不能画像を外部URLのまま配信せず、元URLと失敗記録を保持して写真未登録として表示する。403は回避しない。代替の許諾付き公式画像を調査する必要がある。

`data/sources/webp-manifest.json` が変換結果、`data/spot-photo-overrides.json` が公開画像の差し替え。再集計でも差し替えを維持する。`pnpm data:photos:load:local` はローカルのD1/R2だけを更新する。2026-09-27に172ファイルを本番R2にもアップロード済み。

季節の見頃とバスの運行日は別々に扱う。まず上高地の公式FAQを根拠に新緑・花・紅葉の時期を表示。確認日2026-09-27。未調査の路線には確認中と明記する。地点の植生や所在地だけで季節タグを自動推測しない。見頃は天候で変動し、運行期間は対象系統・年度が一致した公式情報のみ表示する。
